## 4. 新增字段

| 字段 | 类型 | 定义 |
| --- | --- | --- |
| Returned | 字符串 | Order ID 是否在唯一退货订单集合中，值为 Yes/No |
| Order Year | 整数 | Order Date 的年份 |
| Order Quarter | 字符串 | Q1、Q2、Q3、Q4 |
| Order Month | 整数 | 1~12 月，支持正确排序 |
| Order Year-Month | 日期 | 订单月份的第一天，支持跨年排序 |

未创建 `Row Profit Ratio`。后续整体利润率统一使用 `SUM(Profit) / SUM(Sales)`，不能用行级利润率的简单平均代替。未创建 Discount Band、高低销售或高低利润分组。

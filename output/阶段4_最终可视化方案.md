# 阶段 4：最终 Tableau 可视化方案

## 1. 分析主线与统一口径

最终分析主线为：整体经营表现 → 时间变化 → 地区差异 → 商品结构 → Sales 与 Profit 的关系 → Discount 与盈利表现的关系。

核心问题是：销售规模与盈利表现是否一致，以及哪些时间、地区和商品存在销售规模与盈利能力不匹配的现象。

统一统计口径：

- 交易明细数：`COUNTD([Row ID])`。
- 订单数：`COUNTD([Order ID])`。
- 客户数：`COUNTD([Customer ID])`。
- 商品销量：`SUM([Quantity])`。
- 销售额：`SUM([Sales])`。
- 利润：`SUM([Profit])`。
- 利润率：`SUM([Profit]) / SUM([Sales])`。
- 平均订单销售额：`SUM([Sales]) / COUNTD([Order ID])`。
- 退货订单数：`COUNTD(IF [Returned] = 'Yes' THEN [Order ID] END)`。

必须在 Tableau 中新建计算字段：

```text
利润率
SUM([Profit]) / SUM([Sales])

平均订单销售额
SUM([Sales]) / COUNTD([Order ID])

交易明细数
COUNTD([Row ID])

退货订单数
COUNTD(IF [Returned] = 'Yes' THEN [Order ID] END)

退货订单率
[退货订单数] / COUNTD([Order ID])
```

## 2. Sheet 1：月度销售额趋势

### 工作表名称

`01_月度销售额趋势`

### 研究问题

2016—2019 年完整 48 个月的销售规模如何变化，哪些月份出现明显高峰或低谷？

### 图表类型

连续时间轴折线图。

### 字段映射

- Columns：`MONTH([Order Year-Month])`，使用连续日期轴。
- Rows：`SUM([Sales])`。
- Marks：Line。
- Detail：无需额外字段。
- Label：默认关闭；仅对少量经阶段 3 确认的关键月份使用注释。

### 统计口径

月度销售额为 `SUM(Sales)`；订单数为 `COUNTD(Order ID)`，不能用交易明细数替代。

### 筛选器

响应 `Order Year`、`Region`、`Category`、`Segment` 四个全局筛选器。

### Tooltip

```text
年月：<订单年月>
销售额：<$#,##0>
订单数：<COUNTD(Order ID)>
利润：<$#,##0;($#,##0)>
```

### 参考线与排序

- 不需要零参考线。
- 日期按连续月份升序，禁止按销售额重新排序。
- 时间范围固定由数据驱动，完整数据应覆盖 48 个月。

### 标题与副标题

- 标题：`月度销售额变化趋势`
- 副标题：`2016—2019 年，按订单年月汇总；部分月份重复出现较高销售表现`

### 交互

- 接受全局筛选器和 State 地图 Filter Action。
- 不作为筛选源，避免点击单个月份后使其他视图失去整体上下文。

### 对应数据发现

2019 年 11 月销售额最高；9 月、11 月、12 月在多个年份重复出现较高销售表现，只能称为季节性线索。

### 需要避免的错误解释

- 不写成“已证明存在稳定季节性规律”。
- 不因单个月份销售额最高而直接解释成促销、节日或客户需求导致。

## 3. Sheet 2：月度利润趋势

### 工作表名称

`02_月度利润趋势`

### 研究问题

月度利润是否与销售规模同步变化，是否存在高销售但利润较弱或亏损的月份？

### 图表类型

连续时间轴折线图，与 Sheet 1 上下对齐。

### 字段映射

- Columns：`MONTH([Order Year-Month])`，连续日期轴。
- Rows：`SUM([Profit])`。
- Marks：Line。
- Analytics：添加 `Profit = 0` 常量参考线。

### 统计口径

- 月度利润：`SUM(Profit)`。
- Tooltip 利润率：`SUM(Profit) / SUM(Sales)`。

### 筛选器

响应全部四个全局筛选器。

### Tooltip

```text
年月：<订单年月>
利润：<$#,##0;($#,##0)>
销售额：<$#,##0>
利润率：<0.00%>
```

### 参考线与排序

- 添加 0 参考线，颜色使用中性深灰，线宽 1px。
- 日期必须与月度销售额趋势使用相同范围、粒度和升序。
- 不与 Sales 共用单轴，也不使用双轴。

### 标题与副标题

- 标题：`月度利润变化趋势`
- 副标题：`与销售趋势对照；利润率按 SUM(Profit) / SUM(Sales) 计算`

### 交互

接受全局筛选器和 State 地图 Filter Action。

### 对应数据发现

完整数据中有 2 个月汇总利润为负；2018 年 11 月销售额较高，但利润率仅约 5.05%。

### 需要避免的错误解释

- 不把销售与利润的不同步直接归因于折扣、地区或品类。
- 不用 `AVG(Profit / Sales)` 计算利润率。

## 4. Sheet 3：Region 销售与盈利表现

### 工作表名称

`03_地区销售与盈利表现`

### 研究问题

四个 Region 的销售规模、利润贡献和盈利效率是否一致？

### 图表类型

横向条形图。

### 字段映射

- Rows：`Region`。
- Columns：`SUM([Sales])`。
- Marks：Bar。
- Size / 条形长度：`SUM(Sales)`。
- Color：计算字段 `[利润率]`，使用以 0 为中心的红—浅灰—青绿发散色。
- Label：`SUM([Profit])`，负利润使用括号格式。

### 统计口径

利润率必须为各 Region 的 `SUM(Profit) / SUM(Sales)`。

### 筛选器

响应全部四个全局筛选器。Region 筛选器选中单一区域时，本图只保留对应条形，这是预期行为。

### Tooltip

```text
地区：<Region 中文别名>
销售额：<$#,##0>
利润：<$#,##0;($#,##0)>
利润率：<0.00%>
订单数：<COUNTD(Order ID)>
客户数：<COUNTD(Customer ID)>
```

### 参考线、排序与标签

- 默认按 `SUM(Sales)` 降序。
- 不设置主观“优秀/较差”阈值。
- 标签只显示 Profit，不再重复显示 Sales；Sales 由轴和条形长度表达。

### 标题与副标题

- 标题：`各地区销售规模与盈利效率`
- 副标题：`条形长度表示销售额，颜色表示利润率，标签表示利润`

### 交互

- 接受全局筛选器。
- 保持为比较基准，不接受 State 地图 Filter Action，避免选中单州后将州数据误显示成地区整体数据。

### 对应数据发现

West 销售额和利润均最高，利润率约 14.94%；Central 销售额排名第三但利润排名第四，利润率约 7.92%。

### 需要避免的错误解释

- 不按 Sales 排名直接定义“最好地区”。
- 不说明地区本身导致利润率差异。

## 5. Sheet 4：State 销售—利润地图

### 工作表名称

`04_州销售利润地图`

### 研究问题

哪些 State 具有较大销售规模但利润为负或盈利能力较弱？

### 图表类型

美国符号地图。

### 地理设置

- 将 `State` 设置为 Geographic Role → State/Province。
- 将 `Country/Region` 设置为 Country/Region，并在 Edit Locations 中限定 United States。
- Postal Code 不参与主要定位。

### 字段映射

- Detail：`State`。
- Size：`SUM([Sales])`。
- Color：`SUM([Profit])`，使用以 0 为中心的利润发散色。
- Marks：Circle。
- 标签：默认关闭；可只为 Texas 等讲解重点添加注释，不给所有州加名称。

### 统计口径

地图上的 Sales 和 Profit 都是州级汇总；Tooltip 利润率使用 `SUM(Profit) / SUM(Sales)`。

### 筛选器

响应全部四个全局筛选器。

### Tooltip

```text
州：<State>
销售额：<$#,##0>
利润：<$#,##0;($#,##0)>
利润率：<0.00%>
订单数：<COUNTD(Order ID)>
客户数：<COUNTD(Customer ID)>
```

### 颜色、大小与图例

- Size 使用面积编码，范围不要过大，避免 California 等州遮挡邻近州。
- Color 中心固定在 Profit = 0；负利润为红色，正利润为青绿色。
- 地图右下方保留紧凑的 Sales 大小图例和 Profit 颜色图例。

### 标题与副标题

- 标题：`各州销售规模与利润分布`
- 副标题：`圆点大小表示销售额，颜色表示利润；点击州可联动其他分析`

### 交互

- 作为 Filter Action 源。
- 点击 State 后过滤 KPI、两张月度趋势、Sub-Category、Sales × Profit、Discount 与盈利表现。
- 不过滤自身，也不过滤 Region 比较图。
- 清除选择时显示全部值。

### 对应数据发现

Texas 销售额排名第 3，但 Profit 约 -25,729、利润率约 -15.12%，Profit 排名第 49；完整数据中有 10 个负利润 State。

### 需要避免的错误解释

- 不把地图颜色解释为州本身导致盈利或亏损。
- 不使用 Postal Code 填补或定位州。
- 不把圆点面积误当作利润大小。

## 6. Sheet 5：Sub-Category 销售与盈利结构

### 工作表名称

`05_子类别销售盈利结构`

### 研究问题

哪些商品子类别的销售规模与利润贡献、利润率不一致？

### 图表类型

横向条形图。

### 层级

在数据窗格建立层级：`Category → Sub-Category`。默认显示 Sub-Category；Category 同时保留为全局筛选器。

### 字段映射

- Rows：`Sub-Category`。
- Columns：`SUM([Sales])`。
- Marks：Bar。
- Color：`SUM([Profit])`，使用以 0 为中心的利润发散色。
- Label：`SUM([Profit])`。

### 统计口径

- 销售额与利润均使用 SUM。
- 商品数量使用 `SUM(Quantity)`。
- 订单数使用 `COUNTD(Order ID)`。
- 利润率使用 `SUM(Profit) / SUM(Sales)`。

### 筛选器

响应全部四个全局筛选器。

### Tooltip

```text
商品类别：<Category 中文别名>
商品子类别：<Sub-Category>
销售额：<$#,##0>
利润：<$#,##0;($#,##0)>
利润率：<0.00%>
商品数量：<SUM(Quantity)>
订单数：<COUNTD(Order ID)>
```

### 排序与标签

- 默认按 `SUM(Sales)` 降序。
- 必须保留全部 17 个 Sub-Category，不做 Top N 截断。
- 负利润标签用括号或负号，并与红色保持一致。

### 标题与副标题

- 标题：`商品子类别的销售与盈利结构`
- 副标题：`按销售额排序；颜色和标签反映利润表现`

### 交互

- 作为 Filter Action 源。
- 点击某个 Sub-Category 至少过滤 Sheet 6 和 Sheet 7。
- 清除选择时显示全部值。

### 对应数据发现

Tables 销售额排名第 4，但 Profit 约 -17,725、利润率约 -8.56%；Bookcases 和 Supplies 也为负利润。

### 需要避免的错误解释

- 不使用“高销售低利润”等人为标签字段。
- 不因历史负利润直接提出删除商品或停售建议。

## 7. Sheet 6：Sales × Profit 散点图

### 工作表名称

`06_销售额利润关系`

### 研究问题

交易明细层面的 Sales 与 Profit 呈现怎样的分布和关联，哪些极端记录偏离主体分布？

### 图表类型

交易明细级散点图。

### 字段映射

- Columns：`Sales`，以明细级连续度量使用，不聚合或关闭 Aggregate Measures。
- Rows：`Profit`，同样使用明细值。
- Detail：`Row ID`。
- Color：`Discount`，使用单向浅紫—深紫连续色。
- Size：固定小点，不再用第三个业务指标编码大小。
- Analytics：添加 `Profit = 0` 参考线。

### 显示设置

- 点透明度建议 25%–40%，初始值 30%。
- 点边框关闭或使用极浅边框。
- 不删除 Sales、Profit 极端记录，不设置永久范围过滤器。
- 如答辩时需要观察主体分布，只允许临时缩放视图，并明确统计仍基于完整数据。

### 筛选器

响应全部四个全局筛选器、State 地图 Filter Action 和 Sub-Category Filter Action。

### Tooltip

```text
订单编号：<Order ID>
商品名称：<Product Name>
商品类别：<Category 中文别名>
商品子类别：<Sub-Category>
销售额：<$#,##0.00>
利润：<$#,##0.00;($#,##0.00)>
折扣：<0%>
```

### 标题与副标题

- 标题：`交易明细的销售额与利润分布`
- 副标题：`每个点代表一条交易明细；颜色表示折扣，不表示因果关系`

### 交互

- 接受 Sub-Category 和 State 点击筛选。
- 可启用 Highlight Action 作为补充，但不得以高亮代替 Filter Action 的明确筛选状态。

### 对应数据发现

完整数据 Pearson 约 0.479、Spearman 约 0.518；极端记录会影响相关系数大小，但完整数据仍呈正相关。

### 需要避免的错误解释

- 标题不得写成“销售额提高带来利润增长”。
- 不隐藏或删除极端点。
- 不把一个点理解成一个完整订单；观察单位是交易明细。

## 8. Sheet 7：Discount 与盈利表现

### 工作表名称

`07_折扣水平盈利关系`

### 研究问题

不同实际 Discount 取值对应的汇总利润率如何变化，样本量是否足以支持描述？

### 图表类型

精确折扣水平折线 + 圆点图。Discount 只有 12 个实际取值，使用离散点连接可同时展示顺序和样本量。

### 字段映射

- Columns：`Discount`，连续轴，按数值升序。
- Rows：计算字段 `[利润率]`。
- Marks：Line + Circle；可用双轴同步或使用 Line 标记并开启数据点。
- Size：计算字段 `[交易明细数]`，使用较窄范围，避免样本多的 0% 和 20% 折扣遮挡其他点。
- Color：使用单一中性紫色；Profit Margin 的正负由 0 参考线和纵轴位置表达，避免与其它利润发散色图例冲突。
- Analytics：添加 `Profit Margin = 0` 参考线。

### 统计口径

- Profit Margin：`SUM(Profit) / SUM(Sales)`。
- 交易明细数：`COUNTD(Row ID)`。
- 订单数：`COUNTD(Order ID)`。
- 不建立低、中、高折扣分组。

### 筛选器

响应全部四个全局筛选器、State 地图 Filter Action 和 Sub-Category Filter Action。

### Tooltip

```text
折扣：<0%>
销售额：<$#,##0>
利润：<$#,##0;($#,##0)>
利润率：<0.00%>
交易明细数：<COUNTD(Row ID)>
订单数：<COUNTD(Order ID)>
```

### 标题与副标题

- 标题：`折扣水平与盈利表现的观察性关系`
- 副标题：`按实际折扣取值汇总；圆点大小表示交易明细数`

### 对应数据发现

Discount–Profit 的 Pearson 约 -0.219、Spearman 约 -0.543；30%–80% 的实际折扣水平汇总利润均为负，但不同折扣水平样本数差异很大。

### 需要避免的错误解释

- 不写成“折扣导致利润下降”。
- 不忽略样本量差异，特别是 45% 等记录较少的折扣水平。
- 不把折线视为连续实验响应曲线；数据只是 12 个实际取值的观察性汇总。

KPI 不计入 7 张核心分析图，但在 Tableau 中建议建立 4 张独立文本工作表，便于单独控制格式与动态筛选：

| KPI 工作表 | 计算 | 格式 | 标题 |

所有 KPI 必须响应全局筛选器与 State 地图 Filter Action，不写死阶段 3 的总体结果。

## 11. 全局格式规范

### 数字

- Sales、Profit：货币，主轴和标签默认无小数，Tooltip 可保留 0–2 位小数。
- Profit Margin、Returned Order Rate：百分比，保留 2 位小数。
- Discount：百分比，默认 0 位；若出现非整数百分比则保留必要精度。
- Order ID、Customer ID、Row ID：标识符，不参与数学求和。
- 订单数、客户数、Quantity、交易明细数：整数千位分隔。
- 时间轴：`yyyy-MM` 或中文 `yyyy年M月`，必须按真实日期排序。

### 中文 Tooltip

- 删除 Tableau 自动生成的英文字段名和“SUM/AGG”等技术前缀。
- 每张图只保留与研究问题直接相关的 4–7 个字段。
- 统一顺序：维度 → 销售额 → 利润 → 利润率 → 订单/客户/数量。

### 颜色

- Sales 单指标折线：蓝色 `#3B6FB6`。
- Profit 单指标折线：青绿色 `#2A7F74`，并配合 0 参考线。
- Profit / Profit Margin 发散语义：负值红 `#C84545`，0 附近浅灰 `#E5E7EB`，正值青绿 `#2A7F74`。
- Discount 连续色：浅紫至深紫，仅在 Sales × Profit 散点图中表示折扣。
- 背景：近白 `#F7F8FA`；正文：深灰 `#1F2937`。
- 同一颜色不得在其他图中改为无关业务含义。

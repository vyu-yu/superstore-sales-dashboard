# 阶段 4：Tableau Dashboard 布局方案

## 1. Dashboard 基本设置

- Dashboard 名称：`电商销售与经营特征分析`
- 固定尺寸：`1440 × 960 px`
- 使用场景：电脑展示、课堂投影与答辩录屏。
- 调整理由：在约 1440 × 900 的建议范围上增加 60 px 高度，保证 17 个 Sub-Category、两张上下对齐的时间趋势图和地图仍有足够可读空间。
- 容器方式：以 Tiled 为主，局部 Floating 只用于图例或重置说明；避免大量浮动对象导致不同设备错位。
- 外边距：左右 20 px，上下 16 px。
- 图表间距：10–12 px。
- 背景：`#F7F8FA`；图表容器使用白色或极浅灰，不使用厚重边框。

## 2. 页面信息层级

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ 标题与分析问题                         年份  地区  商品类别  客户类型  恢复说明 │
├──────────────────────────────────────────────────────────────────────────────┤
│      总销售额      │       总利润       │      唯一订单数     │    整体利润率 │
├──────────────────────────────────────────────────────────────────────────────┤
│ 月度销售额变化趋势                                                         │
├──────────────────────────────────────────────────────────────────────────────┤
│ 月度利润变化趋势                                                           │
├──────────────────────────────────────────────────────┬───────────────────────┤
│ 各州销售规模与利润分布                               │ 各地区销售与盈利效率  │
├──────────────────────────────┬───────────────────────┬───────────────────────┤
│ 商品子类别销售与盈利结构     │ 交易明细销售额利润分布 │ 折扣水平与盈利表现    │
└──────────────────────────────┴───────────────────────┴───────────────────────┘
```

阅读顺序从上到下、从左到右：总体指标 → 时间变化 → 地区差异 → 商品结构与关系分析。

## 3. 区域尺寸与占比

| 区域 | 建议高度 | 宽度安排 | 页面占比 | 说明 |
| --- | ---: | --- | ---: | --- |
| 标题与筛选器 | 52 px | 标题 50%，筛选器 50% | 5% | 标题左对齐；4 个筛选器横向排列 |
| KPI 区 | 76 px | 4 个等宽容器 | 8% | 数字突出，标题简短，不使用装饰图标 |
| 时间分析区 | 210 px | 全宽；上下各约 100 px | 22% | 两张图共享相同时间逻辑和横轴范围 |
| 地区分析区 | 200 px | State 地图约 66%，Region 图约 34% | 21% | 地图承担交互入口；Region 保留比较基准 |
| 底部分析区 | 320 px | Sub-Category 42%，Sales×Profit 29%，Discount 29% | 33% | 17 个子类别需要最高的底部容器 |
| 留白与间隔 | 约 102 px | 外边距、标题、图例和容器间距 | 11% | 不堆满屏幕；避免对象贴边 |

实际制作时允许在 ±10 px 范围微调，但不压缩 Sub-Category 图到无法显示 17 行，也不把两张时间趋势合并成单轴。

## 4. 顶部标题与筛选器

### 标题区

- 主标题：`电商销售与经营特征分析`
- 副标题：`销售规模与盈利表现是否一致？时间、地区和商品结构中的不匹配现象`
- 标题左对齐，不使用大面积彩色标题条。

### 筛选器位置

四个全局筛选器放在标题区右侧，横向排列：

1. `Order Year` → 显示名“订单年份”，下拉多选。
2. `Region` → 显示名“地区”，下拉多选。
3. `Category` → 显示名“商品类别”，下拉多选。
4. `Segment` → 显示名“客户类型”，下拉多选。

筛选器使用紧凑下拉样式，并显示“全部”。不增加 Postal Code、Customer Name、Product Name、City 等高基数主筛选器。

## 5. KPI 区域

四个 KPI 横向等宽，每个约 337 px 宽，容器间留 10–12 px：

- 总销售额
- 总利润
- 唯一订单数
- 整体利润率

视觉层级：KPI 名称 10–11 pt，数字 20–24 pt，说明文字最多一行。数字必须由 Tableau 计算并随筛选器和 State Action 动态变化。

KPI 不使用红绿底色填满整个卡片；只有总利润或利润率为负时，允许数字本身显示为红色。

## 6. 时间分析区

- Sheet 1 在上，Sheet 2 在下。
- 两图使用同一横向范围、相同左边距和相同月份刻度。
- 上图可隐藏重复的横轴标题，下图保留年月轴。
- 图表之间只留 4–6 px，使其视觉上形成一组。
- 销售额使用蓝线；利润使用青绿线并添加 0 参考线。
- 注释最多 2–3 个关键月份，避免每个点显示标签。

时间分析区用于对照，不把 Sales 和 Profit 强行放入同一单轴或双轴。

## 7. 地区分析区

### State 地图

- 占地区分析区约 66% 宽度。
- 地图保持美国本土范围，避免过多底图细节。
- Size 图例和 Profit 颜色图例放在地图右下角或底部，不遮挡符号。
- 点击 State 后触发过滤动作。

### Region 对比

- 占地区分析区约 34% 宽度。
- 只显示 4 个横向条形，字体可略大于普通分类轴。
- 图例放在 Region 图右上角或容器底部，标题明确为“利润率”。
- 不接受 State 地图动作，始终保留地区层级比较基准。

## 8. 底部分析区

### Sub-Category

- 宽度约 42%，高度约 320 px。
- 显示全部 17 个子类别，按 Sales 降序。
- 负利润条形使用红色，正利润使用青绿色；标签显示 Profit。
- 点击条形过滤右侧两张关系图。

### Sales × Profit

- 宽度约 29%。
- 点大小固定为较小尺寸，透明度初始设置 30%。
- Discount 使用连续紫色图例，图例靠右上或底部横向放置。
- 保留 Profit = 0 参考线。

### Discount 与盈利表现

- 宽度约 29%。
- 使用折线和圆点；圆点大小表示交易明细数。
- 利润率 0 参考线必须明显但不抢视觉焦点。
- 不使用“低折扣/高折扣”等人为色带。

## 9. 全局筛选器作用范围

普通 Quick Filter 的作用范围如下：

| 筛选器 | 4 个 KPI | 月度 Sales | 月度 Profit | Region | State 地图 | Sub-Category | Sales×Profit | Discount | Returns 备用 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Order Year | 是 | 是 | 是 | 是 | 是 | 是 | 是 | 是 | 是 |
| Region | 是 | 是 | 是 | 是 | 是 | 是 | 是 | 是 | 是 |
| Category | 是 | 是 | 是 | 是 | 是 | 是 | 是 | 是 | 是 |
| Segment | 是 | 是 | 是 | 是 | 是 | 是 | 是 | 是 | 是 |

实现方式：在 Tableau 中对每个筛选器选择 “Apply to Worksheets → Selected Worksheets”，明确选中 7 张核心图、4 张 KPI 和 Returns 备用工作表。不要依赖不透明的默认作用范围。

## 10. Dashboard 动作设计

### Action A：State 地图过滤

- 类型：Filter Action。
- 源工作表：`04_州销售利润地图`。
- 运行方式：Select。
- 目标工作表：4 个 KPI、`01_月度销售额趋势`、`02_月度利润趋势`、`05_子类别销售盈利结构`、`06_销售额利润关系`、`07_折扣水平盈利关系`。
- 不过滤：State 地图自身、`03_地区销售与盈利表现`。
- 清除选择：Show all values。
- 用途：查看选定 State 在时间、商品和关系图中的表现，同时保留 Region 基准。

### Action B：Sub-Category 过滤

- 类型：Filter Action。
- 源工作表：`05_子类别销售盈利结构`。
- 运行方式：Select。
- 目标工作表：`06_销售额利润关系`、`07_折扣水平盈利关系`。
- 可选目标：答辩时若希望 KPI 同步，可在测试后增加 4 个 KPI；默认不增加，以免点击条形后顶部总览突然失去上下文。
- 清除选择：Show all values。
- 用途：检查特定子类别中的 Sales–Profit 分布和折扣水平盈利表现。

### 普通 Filter 与 Action 的区别

- `Order Year`、`Region`、`Category`、`Segment` 使用普通全局 Quick Filter。
- State 和 Sub-Category 点击联动使用 Filter Action。
- 不使用高亮替代明确筛选；Highlight Action 只能作为鼠标悬停辅助。

## 11. 恢复全部数据

恢复机制采用两层：

1. 清除 State 或 Sub-Category 选择时，Filter Action 设置为 `Show all values`。
2. 保留 Tableau 工具栏的 `Revert` 功能，并在筛选器右侧显示简短文字：`恢复全部：清除选中标记，并点击工具栏“还原”重置筛选器`。

如果所用 Tableau 版本支持稳定的 Reset/Revert 按钮，可在筛选器最右侧放置一个小型“恢复全部”按钮；不得安装不必要的第三方扩展。

## 12. 图例规划

- State 地图：Sales 大小图例 + Profit 发散色图例，放在地图容器内右下方。
- Region：Profit Margin 发散色图例，标题必须写“利润率”。
- Sub-Category：Profit 发散色图例，标题必须写“利润”。
- Sales × Profit：Discount 连续紫色图例，标题写“折扣”。
- Discount 图：不需要颜色图例；点大小图例标题写“交易明细数”。

图例只放在使用该编码的图附近，不在页面顶部集中堆放多个含义不同的色带。

## 13. 颜色与格式一致性

### 颜色语义

- Sales 单指标：蓝色 `#3B6FB6`。
- Profit / Profit Margin 正值：青绿 `#2A7F74`。
- Profit / Profit Margin 负值：红色 `#C84545`。
- 0 附近：浅灰 `#E5E7EB`。
- Discount：浅紫—深紫连续色，只表达折扣大小。

发散色图统一以 0 为中心。Profit 和 Profit Margin 虽然单位不同，但正负业务语义一致；图例标题必须明确单位，防止混淆。

### 数字格式

- Sales / Profit：`$#,##0`；Tooltip 可用 `$#,##0.00`。
- Profit Margin / Returned Order Rate：`0.00%`。
- Discount：`0%`，必要时保留额外精度。
- 订单数、客户数、Quantity、交易明细数：`#,##0`。
- 年月：`yyyy-MM` 或 `yyyy年M月`。

## 14. 中文展示与文字规范

- 工作表标题使用自然中文，不显示 `SUM(Sales) by ...` 等默认标题。
- 轴标题简化为“销售额”“利润”“利润率”“折扣”。
- Tooltip 使用字段中文显示名，不显示 SUM、AGG、COUNTD 等技术前缀。
- Category 别名：Furniture → 家具，Office Supplies → 办公用品，Technology → 技术产品。
- Segment 别名：Consumer → 消费者，Corporate → 企业，Home Office → 家庭办公。
- Region 别名：West → 西部，East → 东部，Central → 中部，South → 南部。
- 底图中的州名可保留英文专名；Tooltip 字段标签使用中文。

## 15. 留白与视觉密度原则

- 不给每个图表加粗边框，使用留白和浅灰分隔线建立层级。
- 图表标题与绘图区之间保留 4–8 px。
- KPI 数字周围保留足够留白，不添加图标、进度条或装饰性迷你图。
- 时间趋势只标少量关键点；地图默认不显示所有州标签；散点图不显示数据标签。
- 底部三个图保持相同顶部和底部对齐，避免参差。
- 如果投影后字体过小，优先减少副标题或图例占用，不删除核心数据点和类别。

## 16. Returns 最终定位

- `备用_各地区退货订单率` 保留在工作簿中，但不拖入主 Dashboard。
- 答辩时可作为备用工作表打开，说明 West 订单级退货率较高。
- 退货率始终按唯一订单计算。
- 不允许将 Returned=Yes 的 800 条商品明细称为 800 个退货订单。
- 不允许据此声称某一具体商品被退货。

## 17. 阶段 5 实施事项

现有 `superstore_clean.csv` 已包含全部所需字段，不需要修改数据，也不需要新增 Python 处理程序。阶段 5 只需：

- 连接清洗 CSV 并确认字段类型。
- 设置 State 地理角色和 United States 位置上下文。
- 创建 5 个 Tableau 计算字段。
- 设置中文显示名、类别值别名和 Category → Sub-Category 层级。
- 建立 7 张核心图、4 张 KPI、1 张 Returns 备用图。
- 配置 4 个全局筛选器和 2 个 Filter Action。
- 在筛选状态下核对 KPI、订单数和利润率口径。
